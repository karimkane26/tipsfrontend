Framework & Rendu
⚡ Next.js
Le squelette de tout projet. Gère routing, SSR, SSG, API routes et optimisation des assets.
Tips à retenir
  • Utiliser app/ router (App Router) pour les nouveaux projets
  • Privilegier generateStaticParams pour les pages dynamiques statiques
  • Activer next/image pour toutes les images
  • Utiliser les Server Components par défaut, Client seulement si besoin d'interactivité
Librairie UI
⚛️ React
Base de toute l'UI. Composants réutilisables, hooks pour la logique, state pour la réactivité.
Tips à retenir
  • Découper en petits composants (1 rôle = 1 composant)
  • Utiliser useState / useEffect avec parcimonie
  • Préférer useCallback et useMemo si perf critique
  • Nommer les composants en PascalCase, les hooks en camelCase
Styling
🎨 Tailwind CSS
CSS utilitaire. On stylise directement dans le JSX avec des classes prêtes à l'emploi.
Tips à retenir
  • Utiliser cn() (clsx + tailwind-merge) pour les classes conditionnelles
  • Définir les couleurs custom dans tailwind.config.ts
  • Utiliser les variantes responsives : md:, lg:
  • Éviter les styles inline, tout passer par Tailwind
Composants UI
🧩 shadcn/ui
Composants copiables dans le projet (pas une dépendance). Basés sur Radix + Tailwind, entièrement personnalisables.
Tips à retenir
  • Installer seulement les composants nécessaires (npx shadcn@latest add button)
  • Modifier directement les fichiers dans components/ui/
  • Utiliser la variante asChild pour composer les composants
  • Consulter ui.shadcn.com pour les exemples de composition
Accessibilité
♿ Radix UI
Primitives headless (sans style). Gère l'accessibilité, le clavier, le focus trap pour les interactions complexes.
Tips à retenir
  • Utilisé indirectement via shadcn/ui dans la plupart des cas
  • Utiliser directement pour des composants très custom (Slider, Tooltip, etc.)
  • Toujours garder les attributs ARIA générés par Radix
Animations
✨ Framer Motion
Animations déclaratives pour React. Transitions de page, animations au scroll, micro-interactions fluides.
Tips à retenir
  • Utiliser <motion.div> + initial, animate, exit
  • staggerChildren pour animer des listes en cascade
  • Entourer les routes de <AnimatePresence> pour les transitions de page
  • Préférer layout prop pour les animations de layout automatiques
Icônes
🔷 Lucide
Bibliothèque d'icônes SVG cohérentes, légères, tree-shakable (seules les icônes utilisées sont incluses).
Tips à retenir
  • Importer individuellement : import { Search } from 'lucide-react'
  • Passer size, color, strokeWidth en props
  • Utiliser lucide.dev pour rechercher les icônes disponibles
Déploiement
▲ Vercel
Plateforme de déploiement optimisée pour Next.js. Preview automatique par branche, CDN mondial, domaines.
Tips à retenir
  • Connecter le repo GitHub → déploiement automatique à chaque push
  • Utiliser les Preview Deployments pour tester avant de merger
  • Gérer les variables d'env dans le dashboard Vercel (pas dans le code)
  • Activer Vercel Analytics depuis le dashboard projet
Sécurité & Performances
🔒 HSTS + Priority Hints
HSTS force HTTPS. Priority Hints indique au navigateur quelles ressources charger en priorité.
Tips à retenir
  • HSTS activé automatiquement sur Vercel (rien à faire)
  • Ajouter fetchpriority="high" sur l'image hero (LCP)
  • Vérifier les headers de sécurité avec securityheaders.com
SEO & Partage
🔗 Open Graph
Balises méta qui contrôlent l'aperçu du site sur les réseaux sociaux (titre, image, description).
Tips à retenir
  • Définir dans Next.js via metadata ou generateMetadata()
  • Image OG recommandée : 1200×630px
  • Tester avec opengraph.xyz ou les debuggers Twitter/FB
  • Créer une image OG dynamique avec next/og (ImageResponse)
